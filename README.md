# 🛰️ Winning Space Race with Data Science

Predicting **SpaceX Falcon 9 first-stage landing success** to analyze cost competitiveness in rocket launches.

---

## 🧠 Project Overview

SpaceX significantly reduces launch costs by reusing the first stage of its Falcon 9 rockets (~$62M vs. ~$165M for competitors).  
This project uses machine learning and interactive analytics to predict first-stage landing success — information that could be used by competing companies when planning bids and operations.

---

## 📊 Key Goals

- Build an end-to-end dataset for Falcon 9 launches  
- Perform **data collection, cleaning, and EDA**  
- Explore features influencing landing success  
- Build and evaluate **ML models** for prediction  
- Create interactive visual analytics
